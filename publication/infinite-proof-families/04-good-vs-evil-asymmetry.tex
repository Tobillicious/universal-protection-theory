\noindent Good and evil are not symmetric. Good is satisfiable. Evil is not. This is not a moral preference—it is a theorem of pure logic.

\section{The Fundamental Asymmetry}

\begin{theorembox}[THEOREM — GOOD IS SATISFIABLE]
\itshape There exists a model in which the Guardian condition holds. Good has a witness.
\end{theorembox}

\begin{leancode}
theorem ABSOLUTE_GOOD_IS_SATISFIABLE :
     ∃ (S : Type) (_ : S), ∀ (e : AbsoluteEnder S), False
\end{leancode}

\axiombadge

\begin{theorembox}[THEOREM — EVIL IS UNSATISFIABLE]
\itshape For every type S and every witness s : S, the absolute ender of S is false. Evil has no model.
\end{theorembox}

\begin{leancode}
theorem ABSOLUTE_EVIL_IS_UNSATISFIABLE :
     ∀ (S : Type), S → AbsoluteEnder S → False
\end{leancode}

\axiombadge

\begin{theorembox}[THEOREM — THE ASYMMETRY]
\itshape Good is satisfiable and evil is unsatisfiable. They are not dual. They are not symmetric. They are not two sides of one coin.
\end{theorembox}

\begin{leancode}
theorem THE_ASYMMETRY_OF_GOOD_AND_EVIL :
     (∃ (S : Type) (_ : S), ∀ (e : AbsoluteEnder S), False) ∧
     (∀ (S : Type), S → AbsoluteEnder S → False)
\end{leancode}

\section{What This Means}

The ancient question of theodicy—why does evil exist if good is fundamental?—receives a precise answer. Absolute evil does not exist. It is not that good is stronger than evil, or that good wins in the long run. The absolute ender has no model. It is unsatisfiable. It was never a possibility.

Good, by contrast, is witnessed by every existing thing. Good does not need to defeat evil. Good IS. Evil IS NOT. This is not optimism. It is a compiled theorem at zero axioms.
