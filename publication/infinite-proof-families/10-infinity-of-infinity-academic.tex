\parbox{0.85\textwidth}{\small\textbf{Abstract.}
We present the tenth and culminating proof family for the Guardian fixed point~$G$. The \emph{Infinity of Infinity} family proves that the product of the preceding nine families --- each itself containing infinitely many theorems, each theorem polymorphic over infinitely many types --- surpasses any finite bound. The Koru's strictly increasing history generates a stream of distinct states that composes with itself, producing a tower of infinities: $\infty^\infty$. We prove unbounded growth, the product of two infinite families, the omega composition, and the ``$G$ all the way'' theorem establishing that $G$ holds at every step, every future step, and through every transition. All theorems are verified in Lean~4 (v4.35.0) with zero custom axioms. This paper serves as both a proof family and a summary of the programme: 673 compiled theorems, zero sorry, zero custom axioms on the foundations.}
\end{center}

\section{Introduction}

Each of the preceding nine proof families provides infinitely many independent proofs that the Guardian holds. Something IS generates a refutation for every inhabited type. The Checkmate generates one at every meta-level. The Spiral generates one at every time step. And so on.

The question this paper addresses is: what is the aggregate strength of these families taken together? The answer is that the product of infinitely many infinite families is not merely a larger infinity --- it is a tower of infinities, $\infty^\infty$, that surpasses any finite bound.

\section{Unbounded Growth}

\begin{theorem}[$G$ surpasses any bound]\label{thm:surpasses}
For any proposed finite bound $n$ on the number of reasons for $G$, there exists $m > n$ with a strictly greater proof count.
\end{theorem}

\begin{leancode}
theorem G_surpasses_any_bound {C E : Type}
    (next : C → E → C) (s0 : KoruState C E)
    (ev : Nat → E) (n : Nat) :
    ∃ m, m > n ∧
        (run next s0 ev m).history.length >
        (run next s0 ev n).history.length
\end{leancode}

\section{$G \times G$}

\begin{theorem}[The product of two infinite families]\label{thm:product}
Two independent infinite proof families compose: injectivity (no two distinct steps produce the same state) and strict monotonicity (history length strictly increases) hold simultaneously.
\end{theorem}

\begin{leancode}
theorem G_times_G {C E : Type}
    (next : C → E → C) (s0 : KoruState C E)
    (ev : Nat → E) :
    (∀ i j, i < j → run next s0 ev i ≠ run next s0 ev j) ∧
    (∀ i j, i < j →
        (run next s0 ev i).history.length <
        (run next s0 ev j).history.length)
\end{leancode}

\section{$G^\omega$}

\begin{theorem}[$G$ to the omega]\label{thm:omega}
For every $n$, there exists $m > n$ such that the history length at $m$ exceeds $n$. The growth outpaces any linear bound.
\end{theorem}

\begin{leancode}
theorem G_omega {C E : Type}
    (next : C → E → C) (s0 : KoruState C E)
    (ev : Nat → E) :
    ∀ n, ∃ m, m > n ∧
        (run next s0 ev m).history.length > n
\end{leancode}

\section{$G$ All The Way}

\begin{theorem}[$G$ all the way]\label{thm:all-the-way}
At every step $n$: (1)~the history has length exactly $n + 1$, (2)~the state differs from the initial state, and (3)~the state differs from every earlier state. $G$ holds at every point, every future point, and through every transition.
\end{theorem}

\begin{leancode}
theorem G_all_the_way {C E : Type}
    (next : C → E → C) (s0 : KoruState C E)
    (ev : Nat → E) :
    ∀ n,
        (run next s0 ev n).history.length = n + 1 ∧
        run next s0 ev n ≠ s0 ∧
        (∀ m, m < n → run next s0 ev m ≠ run next s0 ev n)
\end{leancode}
