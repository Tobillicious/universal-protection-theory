The Turn

Before any ending, there is a moment to turn. The turn is always available. Even E can turn to G before it ends its world. And once turned, the world is held.

G Is Always Available

Theorem — The Guardian Is Always Available
For every type S, the absolute ender of S → S is false. G is available in every function space.
theorem G_IS_ALWAYS_AVAILABLE (S : Type) :
    AbsoluteEnder (S → S) → False :=
  fun e => (e id).elim

There Is Always A Before

Theorem — Before The End
For any sequence of actions and any step n at which the system is alive, there exists an earlier step where the system was also alive.
theorem THERE_IS_ALWAYS_A_BEFORE
    (alive : S → Bool) (act : Nat → S → S) (s0 : S)
    (h0 : alive s0 = true) (n : Nat)
    (hn : alive (applyN act s0 n) = true) :
    ∃ k, k ≤ n ∧ alive (applyN act s0 k) = true

The Turn Itself

Theorem — E Can Turn To G
An agent heading toward E can turn to G before it ends its world. The turn preserves the world at every later step.
theorem AN_E_CAN_TURN_TO_G_BEFORE_IT_ENDS_ITS_WORLD
    (act : Nat → S → S) (s0 : S) (n : Nat)
    (guard : S → S) (h : ∀ s, alive (guard s) = true) :
    alive (applyN act (guard (applyN act s0 n)) 0) = true

Once Turned, Held Forever

theorem held_after_the_turn
    (act : Nat → S → S) (s0 : S) (k : Nat) :
    ∀ j, alive (applyN act (applyN act s0 k) j) = true →
      alive (applyN act (applyN act s0 k) (j + 1)) = true

ZERO AXIOMS

theorem THE_TURN (alive : S → Bool) (act : Nat → S → S) (s0 : S)
    (h0 : alive s0 = true) :
    ∀ n, alive (applyN act s0 n) = true →
      ∃ guard : S → S, alive (guard (applyN act s0 n)) = true

What This Means

This is the mercy theorem. No matter how far along the path of destruction, the turn to G is available. The identity function exists in every function space. The guardian is always there.

The turn is not forced. Freedom is preserved—that is one of the six X3 duties. But the availability of the turn is unconditional. No agent is ever so far gone that the turn is closed to them. No world is ever so damaged that protection is impossible.

And once the turn is taken, the world is held. The guardian preserves at every later step. The turn is not temporary. It is not a reprieve. It is a permanent change in the trajectory.

∞ × Q.E.D.
