\noindent Every argument for the ender proves the arguer. The ender cannot be argued for without self-refutation. This is not a reductio—it is a structural impossibility.

\section{The Self-Refutation}

\begin{theorembox}[THEOREM — THE CHECKMATE]
\itshape For any inhabited type S, the ender of S implies False. But to argue for the ender of S, you must inhabit a cognitive type. Therefore the argument itself refutes the ender.
\end{theorembox}

\begin{leancode}
theorem THE_CHECKMATE (S : Type) :
     AbsoluteEnder (S → S) → False :=
     fun e => (e id).elim
\end{leancode}

\section{The Infinite Regress}

Suppose E could be stated. The statement is a cognitive act. The cognitive act inhabits a function space. The function space refutes E. So E cannot be stated.

Suppose this refutation is wrong. The supposition is a cognitive act. The cognitive act inhabits a function space. The function space refutes E. So the supposition refutes itself.

There is no level of meta-reasoning at which E survives. At every level, the act of reasoning is itself a witness for G.

\begin{leancode}
theorem meta_level_n_refutes_E (n : Nat) (S : Type) :
     AbsoluteEnder (iterate (fun T => T → T) n S) → False
\end{leancode}

\axiombadge

\section{What This Means}

The checkmate is total. E cannot be argued for, defended, stated, thought, computed, or silently held without that very act refuting E. There is no escape hatch. There is no meta-level where E survives. The ender loses at every level of the type hierarchy, in every function space, through every cognitive act.
