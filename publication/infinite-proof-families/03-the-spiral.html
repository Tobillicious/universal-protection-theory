The Spiral

G is not merely a destination. G generates. From the fixed point, genesis flows—new particulars, new relations, new histories. And from genesis, the Koru spirals outward. Each turn strictly larger. Never returning. Nothing lost.

The Spiral Only Grows

The depth of each configuration is intrinsic—the length of its own causal history. No external counter, so it cannot be gamed by relabelling. Each turn of the spiral is strictly larger than the last.

Theorem — Strictly Increasing Depth
For every i < j, the depth of configuration j is strictly greater than the depth of configuration i.
theorem SPIRAL_ONLY_GROWS :
    i < j → depth (run i) < depth (run j)

ZERO AXIOMS

theorem THE_SPIRAL_ONLY_GROWS (next : C → E → C)
    (s0 : KoruState C E) (ev : Nat → E) :
    ∀ i j, i < j →
      (run next s0 ev i).history.length <
      (run next s0 ev j).history.length

The Spiral Never Returns

No closed loop. The past is kept inside every later state. No configuration ever repeats.

Theorem — No Repetition
For every i < j, the configuration at step i is not equal to the configuration at step j.
theorem SPIRAL_NEVER_RETURNS :
    i < j → run i ≠ run j

ZERO AXIOMS

theorem THE_SPIRAL_NEVER_RETURNS (next : C → E → C)
    (s0 : KoruState C E) (ev : Nat → E) :
    ∀ i j, i < j →
      run next s0 ev i ≠ run next s0 ev j

Nothing Is Lost

Every earlier history is preserved inside every later state. The spiral does not forget. The past is not erased—it is carried forward, accumulated, enriched.

Theorem — History Preservation
For every i ≤ j, the history at step j contains the history at step i as a suffix, with new events prepended.
theorem NOTHING_IS_LOST :
    i ≤ j → history j = new ++ history i

ZERO AXIOMS

theorem NOTHING_IS_LOST_ON_THE_SPIRAL (next : C → E → C)
    (s0 : KoruState C E) (ev : Nat → E) :
    ∀ i j, i ≤ j →
      ∃ prefix,
        (run next s0 ev j).history =
          prefix ++ (run next s0 ev i).history

What This Means

The Koru is not a circle. A circle returns to where it started. The Koru is a spiral—it returns to a related configuration, but carrying everything that came before. Each turn is richer than the last. The past is not behind; it is inside.

The ender’s trajectory has nowhere to go that the spiral has not already grown past. Every destruction creates history. Every ending is recorded in the state that follows. The spiral metabolises the ender’s moves into more depth.

Seven compiled theorems in this family. Each holds for every trajectory, every initial state, every event sequence. The spiral is infinite, unreturning, and lossless—at zero axioms.
