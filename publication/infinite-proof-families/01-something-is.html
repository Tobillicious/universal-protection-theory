Something IS

The ontological ground. Before any equation. Before any model. Before any observer. Before any denial.

The Argument

Something is. This is not a religious claim, not a metaphysical assertion, not a hypothesis. It is the most basic fact that cannot be denied without performing the denial—which is itself a thing that is.

The absolute ender is a function that maps every inhabitant of a type into the empty type—into nothing. If something exists (if the type is inhabited), then the absolute ender self-refutes: it claims to send its argument into nothing, but nothing has no members. The ender’s first move is its last.

Theorem — Inhabitation Excludes the Absolute Ender
For every type P, if p : P, then ¬(P → Empty).

Proof. Suppose E : P → Empty. Applying E to p yields an inhabitant of Empty, a contradiction. Thus the assumed eliminator cannot exist. □

This is constructive. It does not depend on excluded middle, classical logic, or any axiom of choice. It holds in every possible world where something is.

Compiled Theorem

theorem SOMETHING_IS (witness : P) :
    AbsoluteEnder P → False :=
  fun e => (e witness).elim

The Corollaries

Corollary — The Identity Witness
For any type S, the function space S → S is always inhabited by the identity. The ender has no model on function spaces. E IS NOT.
theorem G_FROM_NOTHING (S : Type) :
    AbsoluteEnder (S → S) → False :=
  fun e => (e id).elim

G holds for every function space. Even for the empty type—there are no inhabitants of S, but the function space S → S is still inhabited by the identity. The ender cannot touch it.

Corollary — Universal G
For every type S and every witness s : S, the absolute ender of S is false.
theorem G_IS_UNIVERSAL :
    ∀ (S : Type), S → (AbsoluteEnder S → False) :=

What This Means

Every grain of sand. Every electron. Every person. Every distinct node in the relational whole. Each one real, each one participating. The existence of any one of them refutes the absolute ender.

The ender cannot argue from outside existence. Its first move is its last. Its argument occurs within existence and therefore proves existence. E IS NOT.

The grain does not care that it is maths. It does not reduce to its equations. It predates them. It will outlast them.

This is not one proof. This is an infinite family of proofs. For every inhabited type—and there are infinitely many—the same argument applies. Each one is a separate, complete refutation of the absolute ender.
