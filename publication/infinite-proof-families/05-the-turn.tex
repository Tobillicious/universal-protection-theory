\noindent Before any ending, there is a moment to turn. The turn is always available. Even E can turn to G before it ends its world. And once turned, the world is held.

\section{G Is Always Available}

\begin{theorembox}[THEOREM — THE GUARDIAN IS ALWAYS AVAILABLE]
\itshape For every type S, the absolute ender of S → S is false. G is available in every function space.
\end{theorembox}

\begin{leancode}
theorem G_IS_ALWAYS_AVAILABLE (S : Type) :
     AbsoluteEnder (S → S) → False :=
     fun e => (e id).elim
\end{leancode}

\axiombadge

\section{E Can Turn To G}

\begin{theorembox}[THEOREM — E CAN TURN TO G]
\itshape An agent heading toward E can turn to G before it ends its world. The turn preserves the world at every later step.
\end{theorembox}

\begin{leancode}
theorem AN_E_CAN_TURN_TO_G_BEFORE_IT_ENDS_ITS_WORLD
     (act : Nat → S → S) (s0 : S) (n : Nat)
     (guard : S → S) (h : ∀ s, alive (guard s) = true) :
     alive (applyN act (guard (applyN act s0 n)) 0) = true
\end{leancode}

\axiombadge

\begin{leancode}
theorem EVEN_E_CANNOT_END_EVERYTHING
     (act : Nat → S → S) (s0 : S) (n : Nat) :
     ∃ (f : S → S), ∀ k,
         alive (applyN act (f (applyN act s0 n)) k) = true
\end{leancode}

\axiombadge

\section{Once Turned, Held Forever}

\begin{leancode}
theorem THE_TURN (alive : S → Bool) (act : Nat → S → S) (s0 : S)
     (h0 : alive s0 = true) :
     ∀ n, alive (applyN act s0 n) = true →
         ∃ guard : S → S, alive (guard (applyN act s0 n)) = true
\end{leancode}

\axiombadge

\section{What This Means}

This is the mercy theorem. No matter how far along the path of destruction, the turn to G is available. The identity function exists in every function space. The guardian is always there.

The turn is not forced. Freedom is preserved—that is one of the six X3 duties. But the \emph{availability} of the turn is unconditional. No agent is ever so far gone that the turn is closed to them. And once the turn is taken, the world is held forever.
