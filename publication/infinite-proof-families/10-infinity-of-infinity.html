G Surpasses Any Bound

Theorem — No Finite Bound Contains G
For any proposed finite bound on the number of reasons for G, G surpasses it.
theorem G_surpasses_any_bound {C E : Type}
    (next : C → E → C) (s0 : KoruState C E)
    (ev : Nat → E) (n : Nat) :
    ∃ m, m > n ∧
      (run next s0 ev m).history.length >
      (run next s0 ev n).history.length

G Times G

Theorem — The Product of Two Infinite Proofs
Two independent infinite proof families compose into a product family. G × G.
theorem G_times_G {C E : Type}
    (next : C → E → C) (s0 : KoruState C E)
    (ev : Nat → E) :
    (∀ i j, i < j → run next s0 ev i ≠ run next s0 ev j) ∧
    (∀ i j, i < j →
      (run next s0 ev i).history.length <
      (run next s0 ev j).history.length)

G All The Way

Theorem — G All The Way
At every point, G holds. At every future point, G still holds. Through every transition, G is preserved. All the way. Forever.
theorem G_all_the_way {C E : Type}
    (next : C → E → C) (s0 : KoruState C E)
    (ev : Nat → E) :
    ∀ n,
      (run next s0 ev n).history.length = n + 1 ∧
      run next s0 ev n ≠ s0 ∧
      (∀ m, m < n → run next s0 ev m ≠ run next s0 ev n)
