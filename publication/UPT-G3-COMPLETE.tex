\section{The Single Premise: \SomethingIS}
\label{sec:something-is}

The entire theory rests on one premise: there exists something rather than nothing. In type-theoretic language, there exists an inhabited type.

\begin{definition}[Non-Being]

An \emph{absolute ender} of type $P$ is a function $f : \AbsEnder{P}$. It would carry what-is out of being, into non-being.
\end{definition}

\begin{theorem}[E IS NOT]
\label{thm:e-is-not}
Given a witness $w : P$, there is no absolute ender: $\AbsEnder{P} \to \bot$.
\end{theorem}
\begin{proof}
Suppose $f : \AbsEnder{P}$. Then $f(w) : \NonBeing$. But $\NonBeing$ has no inhabitants. Contradiction.

\end{proof}
