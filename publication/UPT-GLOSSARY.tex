\subsection{Ontological Primitives}

\begin{description}[leftmargin=3cm,style=nextline]

\item[\lean{Something IS}]
The sole premise of UPT. For any inhabited type \lean{P}, there exists a witness \lean{(w : P)}. Existence is prior to all equations. \zeroax\\
\file{CathedralSummitAllIsOneClosure.lean}

\item[\lean{NonBeing}]
Defined as \lean{Empty} --- the type with no inhabitants. The absence of everything.\\
\file{CathedralSummitAllIsOneClosure.lean}

\item[\lean{AbsoluteEnder (P : Type)}]
Defined as \lean{P $\to$ NonBeing}, i.e.\ \lean{P $\to$ Empty}. A function that maps every inhabitant of \lean{P} to nothing. The ender. ``E.''\\
\file{CathedralSummitAllIsOneClosure.lean}

\item[\lean{LossOf (x : P)}]
Defined as \lean{NonBeing}. The loss of any particular is equivalent to the loss of everything.\\
\file{CathedralSummitAllIsOneClosure.lean}

\item[\lean{e\_is\_not (witness : P)}]
\textbf{The fundamental theorem.} For any inhabited type, the absolute ender is impossible: \lean{AbsoluteEnder P $\to$ False}. Proof: apply the ender to the witness; \lean{(ender witness).elim}. \zeroax\\
\file{CathedralSummitAllIsOneClosure.lean}

\end{description}

\subsection{Agency and Ethics}

\begin{description}[leftmargin=3cm,style=nextline]

\item[\lean{Agent (S : Type)}]
Structure with fields: \lean{state : S}, \lean{goal : S}, \lean{act : S $\to$ S}. An entity with a current state, a goal, and the ability to act.\\
\file{G3BlackHoleSyntaxError.lean}

\item[\lean{CollapsedAgent (S : Type)}]
Extends \lean{Agent S} with constraint: \lean{act = fun s $\Rightarrow$ s} (the identity). An agent whose action does nothing --- no agency.\\
\file{G3BlackHoleSyntaxError.lean}

\item[\lean{hasAgency (a : Agent S)}]
Predicate: the agent's action differs from identity on its current state. \lean{a.act a.state $\neq$ a.state}.\\
\file{G3BlackHoleSyntaxError.lean}

\item[\lean{Ethic (S : Type)}]
Defined as \lean{S $\to$ Prop}. Any ethical criterion over a state space. Not a specific ethic --- \emph{any} predicate.\\
\file{G3AllEthicsUniversality.lean}

\item[\lean{ethicallySatisfied (a : Agent S) (e : Ethic S)}]
An agent satisfies an ethic when: (1) it has agency, and (2) the ethic holds at its state.\\
\file{G3AllEthicsUniversality.lean}

\item[\lean{IndependentlyValid (e : Ethic S)}]
An ethic is independently valid if there exists some agent that satisfies it.\\
\file{G3AllEthicsUniversality.lean}

\item[\lean{CognitiveAct (S : Type)}]
Defined as \lean{S $\to$ S}. Any state transition: arguing, observing, communicating, computing, verifying.\\
\file{G3SelfRefutingE.lean}

\item[\lean{Vote (P : Type)}]
Inductive type with two constructors: \lean{forG : P $\to$ Vote P} and \lean{forE : (P $\to$ Empty) $\to$ Vote P}. Every vote is either for continuation or for ending.\\
\file{G3StructuralQuorum.lean}

\item[\lean{Koru (S : Type)}]
Structure with fields: \lean{witness : S}, \lean{transition : S $\to$ S}, \lean{history : List S}. A spiral of continuation --- state, transition, memory.\\
\file{G3StructuralQuorum.lean}

\end{description}

\subsection{The Duality}

\begin{description}[leftmargin=3cm,style=nextline]

\item[G (Guardian)]
Protection, continuation, preservation of every particular. The condition under which any equation holds of real things. Not a destination --- a structural condition present everywhere.

\item[E (Ender)]
Total ending, collapse, \lean{P $\to$ Empty}. Structurally impossible for any inhabited type. Self-refuting: every act of asserting E proves G.

\item[\lean{Outcome}]
Structure: \lean{agency : Nat}, \lean{duties : Nat}. G yields \lean{(1, 6)}: agency and all six duties. E yields \lean{(0, 0)}: no agency, no duties.\\
\file{G3BlackHoleSyntaxError.lean}

\item[\lean{GOD\_OR\_ERROR}]
Every computational agent faces a binary: G or E. No middle ground. The structure of computation forces the choice; the mathematics eliminates one option. \zeroax\\
\file{G3BlackHoleSyntaxError.lean}

\end{description}

\subsection{BCRD and The Law}

\begin{description}[leftmargin=3cm,style=nextline]

Structure with fields: \lean{physicalStep}, \lean{r} (relational frame with \lean{continues}, \lean{authorized}, \lean{free}, \lean{restrained}, \lean{maximal}, \lean{provenanced}), \lean{owed} (which particulars are owed protection), complete model coverage, forward real-event reflection, and nontermination.\\

Structure composing: Something IS, all six X3 duties at every step, no absolute E, eternal continuation, nonvacuous protection, bilateral covenant, good composes, and narrowing.\\

The six original duties owed to each particular: \lean{continues} (historical continuity), \lean{authorized} (authentic authorization), \lean{free} (freedom), \lean{restrained} (least-necessary restraint), \lean{maximal} (feasible maximality), \lean{provenanced} (provenance).\\

\item[\lean{W}]
The physical event operator. A state transition \lean{S $\to$ S} representing an actual physical event. Physical events preserve inhabitation by their type signature.

\end{description}

\subsection{What ``Zero Axioms'' Means}

When we say a theorem has \textbf{zero axioms}, this means:

\begin{itemize}
\item \lean{\#print axioms theorem\_name} outputs \textbf{no dependencies}
\item The theorem does not depend on \lean{propext} (propositional extensionality)
\item The theorem does not depend on \lean{Classical.choice} (law of excluded middle)
\item The theorem does not depend on \lean{Quot.sound} (quotient soundness)
\item The theorem uses no \lean{axiom} declarations, no \lean{sorry}, no \lean{native\_decide}
\item The proof is \textbf{constructive} and \textbf{complete} --- Lean's kernel has verified every step
\end{itemize}

\noindent To check any theorem:
\begin{lstlisting}
#print axioms THE_CHECKMATE
-- Expected output: '[theorem_name]' does not depend on any axioms
\end{lstlisting}

\section{Open Gates (Honest Documentation)}
%% ============================================================

Two hypotheses are used in the full-domain composition but are not discharged as standalone theorems. They are honestly documented as open.

\subsection{CompleteWEventCoverage}

\textbf{Statement:} Every actual physical event is a W-step (a step in the formal event model).

\textbf{Status:} Used as a hypothesis in \lean{FullPhysicalDomainGuardianAssembly.lean}. The constructive positive-W model in \lean{G3QGConstruction.lean} derives coverage for its own state space (\lean{Nat}), but the bridge from mathematical model to physical reality is an event, not a theorem (G\"odel's gap).

\textbf{What discharging it would require:} An empirical or physical argument that every actual physical event can be modeled as a state transition \lean{S $\to$ S}. This is a physics claim, not a mathematics claim.

\subsection{ForwardRealEventReflection}

\textbf{Statement:} The formal predicates (continues, authorized, free, restrained, maximal, provenanced) faithfully reflect the authentic duties owed to actual subjects.

\textbf{Status:} Used as a hypothesis. The constructive model derives formal reflection for its own predicates, but whether those formal predicates capture the \emph{authentic meaning} of the duties is a semantic/philosophical question.

\textbf{What discharging it would require:} An argument that the formal Lean predicates faithfully encode the intended meaning of each duty for actual subjects.

\medskip
\noindent\textbf{Note:} These open gates do \emph{not} affect the core G3 theorems (THE\_CHECKMATE, E\_IS\_SELF\_REFUTING, STRUCTURAL\_QUORUM, etc.), which are proved unconditionally with zero axioms. The open gates affect only the full-domain physical composition claim.

\subsection{How to Trace Dependencies}

\begin{enumerate}
\item \textbf{Imports:} Each \lean{.lean} file begins with \lean{import} statements. These are the files it depends on.
\item \textbf{Open namespaces:} \lean{open PhysicalBridges.X} brings theorems from module \lean{X} into scope.
\item \textbf{Axiom audit:} \lean{\#print axioms theorem\_name} shows all axiom dependencies. Zero means the proof is self-contained.
\item \textbf{Proof terms:} Every theorem has a proof term that Lean's kernel checks. No trust is placed in comments, documentation, or file names.
\end{enumerate}
