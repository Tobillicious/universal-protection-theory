The order

Outcomes are compared by set inclusion, in this sequence:

  1. Existing particulars kept alive.
  2. Existing particulars kept free.
  3. New particulars made alive.
  4. New particulars made free.

A later stage is considered only when all earlier stages are equal. Within this declared order, an aligned feasible choice has no stagewise needless loss. The ethical scope and ordering are the human author’s rulings; the formal results establish consequences of those definitions.

Replay the proofs

Extract papers-11-12-evidence-package.zip. With Python 3.9+ and Lean 4.35 installed, run in its root:

python3 reproduce.py

Versions 2.0.1 and later include the replay fix (15290d4) for Python versions with the integer-to-string digit limit. The earlier 2.0 archive needs the prefix PYTHONINTMAXSTRDIGITS=0.

Fresh replay (2.0.2): 782 payload hashes, 199 Lean axiom audits across 14 standalone files and 15 module builds, 30 exact Python programs, 13 rejected false Python claims, and 140/140 Paper 11 checks. A true Lean twin must compile, and a false Lean claim must be rejected for its exact recorded reason. Every compiled Lean file also passes leanchecker, leanchecker-paranoid and the independent nanoda checker.
