# Objective Bend (`obend`) ↔ Universal Protection Theory Bridge

This directory demonstrates direct integration between **Universal Protection Theory** and [`github.com/emberian/obend`](https://github.com/emberian/obend) (`leanprover/lean4:v4.35.0`), pairing open-recursive specification slots (`Obend.Slot`, `Obend.Logic`) with certified logic-to-silicon hardware emission (`Obend.Lower.SiliconElabFabric`).

## Contents

| Artifact | Purpose |
|---|---|
| `ProtectionEnvelope.obend` | Edition-1 Objective Bend open-recursive specification (`BaseBoundarySpec` + `GMesh43QuorumOverride`) modeling monotone apply-time hold floors, restitution slash slack, and the `3f + 1 = 43` / `2f + 1 = 29` (`f = 14`) G-Mesh Byzantine quorum boundary. |
| `receipts/*.json` | Four standalone `rewrite@1` certificates generated by `obend prove` with explicit support-footprint pins (`supports`) so any overriding layer that mutates a depended-upon field automatically invalidates stale receipts (`moved_pin_blocks`). |
| `ProtectionEnvelopeGate.sv` | Synthesizable 64-bit datapath SystemVerilog hardware boundary emitted from `ProtectionEnvelope.obend` via `obend tapeout --mode comb` (`slots=7, wires=7, regs=7, bels=57`). |
| `tapeout-receipt.json` | Certified `waferspace-signoff@1` hardware tapeout receipt accompanying `ProtectionEnvelopeGate.sv`. |

## Reproducing Standalone Verification With `obend`

With `obend` built on a Linux verification host (`lean/.lake/build/bin/obend`):

```bash
# 1. Typecheck and evaluate the composed open-recursive specification:
obend check ProtectionEnvelope.obend gmesh43Nodes
obend run ProtectionEnvelope.obend gmesh43Nodes

# 2. Re-verify each standalone proof receipt with zero producer state:
for r in receipts/*.json; do
  obend verify "$r"
done

# 3. Re-emit and verify the SystemVerilog hardware gate and signoff receipt:
obend tapeout ProtectionEnvelope.obend \
  --entry gmesh43Nodes \
  --mode comb \
  --out-sv ProtectionEnvelopeGate.sv \
  --out-receipt tapeout-receipt.json
```
