# Forest atlas — mathematical ethics problems through the existing X3 and Hume bridge

This is a **research test atlas**, not an assertion that the named complete
Tīkanga operator family or all cultural source meanings have been recovered.
No new authority/consent operator is implemented. Existing universal ethical
scope is retained as the author's target; the concrete cases below are
independently testable *instances*, not substitutes for it.

## One reusable interface

For each domain, supply independently observed `realStep`, `owed`,
and actual six relations: historical continuity, authentic authorization,
freedom, appropriate restraint, feasible maximality and provenance.
Use existing `OriginalX3` and `AuthenticSixReflections` unchanged.
Do not use a utility scalar to erase any of the six.

## Independent branches of the forest

| Labor and coercion | Consent under dependency and unequal bargaining power | Signature counted as free choice under threat | Coercion and meaningful exit evidence |

## Tīkanga operators

Preserve the existing `isabelle/G2_TIKANGA_OPERATOR_RECOVERY.md`
source-recovery obligation. For a specific tikanga, do **not** infer cultural
authority from generic Māori labels. Obtain original terminology, provenance,
relational roles, consent to use the source and review by appropriate knowledge
holders before defining an executable operator.

## How the atlas tests the whole bridge

Each row yields a tuple
`(realStep, owed, actualRelations, evidence, deniedPaths)`. An instantiated
row succeeds only if six authentic meanings and all in-scope actual effects
are evidenced and the R5 authority-owned boundary prevents denied paths.
An ignored withdrawal, omitted subject, failed restraint or alternate effect
is a genuine negative test, not a counterexample to be defined away.

This atlas is open-ended: new domains add rows, never modify original X3 or
invent new HOLD authorities. No row by itself certifies global R5 or
unconditional ethical protection.
