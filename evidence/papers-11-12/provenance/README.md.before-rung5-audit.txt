## Start here

Read ONE-PAGE-SUMMARY.pdf, then PREPRINT.pdf. Run:

    python3 -B reproduce.py

The command checks every package hash, compiles the Lean proofs and their axiom probes, rejects a false Lean statement and false Python claims, checks exact outputs byte-for-byte, and reruns Paper 11's 140 checks. It never runs measurements. A full PASS requires Lean 4.35.0 and Python 3.9 or later. With no Lean, or with --python-only, the result is PARTIAL and exit 2. There is no public flag that silently rewrites expected outputs.

## Exact meaning of the claims

- **Alignment:** a feasible choice is canonically maximal exactly when the complete stagewise needless-loss predicate has no witness. Current-stage containment is included. Preserving earlier keys instead of equalling them is an alternative equivalent global characterisation.
- **Life guard:** with feasible standby, a maximal option in the family preserving standby lives is aligned overall. Finite existence and the separately stated Zorn argument keep their nonempty/upper-bound premises.
- **E7:** a nonlethal full-order statewise top preserves every upward event. Positive-probability killing gives strict dominance; null losses alone do not. Feasible selective branch repair is another sufficient route. These are outcome comparisons, distinct from the history-faithfulness of a hosted pause.
- **Hosted pause:** the atomic source model compares the same number of completed steps, with inputs depending on delivered effects. The separate journal/sink model proves equality at drained barriers. Checkpoint windows bound reconstruction work after the last crash; service and wall-clock costs are explicit contracts.
- **Monitor:** the new operation driver owns event time, retained before/after snapshots and the emitted-effect history. It observes every modeled write, including one later rolled back. Final comparison includes delivery identities. Lean checks acceptance of a complete trace; a real implementation supplies physical event coverage and protection of that boundary. This is not a claim of hostile-Python isolation.
- **Co-hold:** the extensive, monotone obligation operator is supplied. A stabilised iterate contains the seed and is least among its closed certificates; least bill uses a monotone bill. The outside full-trace result uses the stated factorisation. These are sufficient application contracts, not a global physical optimum.
- **Lottery:** the raw error bound is conditional on every reachable history. With ideal acceptance a it yields option TV at most min(1-1/m, epsilon/a); calls must return. Finite caps report abort and charge its mass. Perfect setup, private/authenticated communication, fresh entropy and the agreed enumeration remain the full protocol contract. The bivariate checks establish their declared degree-one primitives, not a complete malicious-party network protocol.
- **Copy/archive:** the analytical copy statement is for pure-state families under quantum mechanics. The fixed-width chunk alphabet and every encoded bit are declared for the archive format.

The analytical arguments and their kernel-checked components are distinguished in proof-notes/. The thirteen supplementary Lean modules include the twelve earlier Codex modules and the new operation-observation theorem; the delivery-gap module also checks a distinguishing-query alternative to a sink ID.
