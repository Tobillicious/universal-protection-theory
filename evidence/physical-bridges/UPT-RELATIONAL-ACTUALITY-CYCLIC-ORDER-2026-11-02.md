This preorder is the **least relation** containing every preservation-inclusion pair: subset inclusion already is reflexive and transitive, so the preorder generated by those pairs is exactly inclusion. ## 2. UPT-CYCLIC-ORDER-01 — proven equivariance under source-faithful orientation

L_N'(Θo)=ρ_N[L_N(o)], F_N'(Θo)=ρ_N[F_N(o)].

**THEOREM.** For every o,p∈O, the canonical four-stage order satisfies

o ≺ p **iff** Θo ≺' Θp.

In particular an outcome is maximal (aligned) in O iff its transformed counterpart is maximal (aligned) in O'. The first-stage inclusion comparison and lack-of-needless-loss diagnostics are preserved too.

**PROOF.** For any bijection ρ, A=B iff ρ[A]=ρ[B], and A⊊B iff ρ[A]⊊ρ[B]. Apply to each of the four stages. Consequently the first different stage remains the first different stage with the identical strict-inclusion direction. This proves order preservation and reflection. Feasible-family bijectivity then carries all potential strict improvers in both directions, so maximality is invariant. QED.
