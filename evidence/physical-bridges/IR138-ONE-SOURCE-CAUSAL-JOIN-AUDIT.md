- **One-policy safe continuation:** the same always-guard action preserves old continuity/options and newly arising continuity/options/registration under EVERY finite no-bypass event stream. This uses an absorbing loss state (cannot pretend a copy reanimates the original).

This is a genuine source-defined rival comparison rather than an arbitrary safe-menu assertion.
- **Adversarial controls:** hidden bypass defeats guard, late installation cannot revive original, adversarial birth can change with the action so fixed-event optimality is NOT universal reactive-world greatestness; forged-consent input cannot override the protective gate.
