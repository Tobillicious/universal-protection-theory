# PR B phase 1 — subject-level semantics before the source join

**4 November 2026 · Research-only review draft · No canon or release edits.**

## Purpose

PR A develops a source-defined BCRD relational frame and genuine before/after covariance. This PR develops the **separate original per-particular semantic obligations**, which will be instantiated against PR A only after its actual source transition is fixed. PR C's first-violation necessity theorem is deliberately deferred.

The target is **not changed**. It is still the six-component `OriginalX3` with explicit owed particular:

1. Historical continuity of the actual same particular, including within-event activity.
2. Authentic authorization—not merely causal participation or account balancing.
3. Executable future freedom/choice over its owed domain.
4. Appropriate lawful restraint.
5. Maximality with respect to the actual full feasible order, not a small sample menu.
6. Faithful source-provenance, independently checked against actual continuing history.

## New Lean module: `ParticularSemanticsAudit.lean`

- `ParticularFrame S P`: a real transition `S → S → Prop`, an owed predicate `S → P → Prop`, and six independently typed, subject-indexed semantic relations. None is identified with charge conservation or a frozen basis label.
- `FullOriginalX3`: *exact reuse* of `OriginalX3Full.OriginalX3`.
- `full_original_x3_iff_six_components`: exact interface contract, not a novel physics theorem.
- `ActualStepPreservesFullX3`: the **PR C goal** is stated as a named open proposition; no theorem constructs it from the mere existence of a frame.
- `each_missing_component_defeats_full_x3`: for every one of the six components, a synthetic event with only that duty missing fails full original X3.
- `all_six_failures_invisible_to_coarse_readout`: all six such events share a generator/charge/reported-origin tuple with a healthy event.
- `no_coarse_readout_decoder_for_full_original_x3`: using inherited `IR132` exact decoder/fibre criterion, that nominal triple cannot exactly determine the six-component X3 status.

**Important scope:** The toy episodes do not establish *actual* BCRD harm or disprove the full theory. They establish that the source-to-subject correspondence must supply independent discriminating information and that an identity label or accounting readout alone is not enough. They also prevent accidental substitution of the two-flag controller proxy.

## PR A ⇢ PR B ⇢ PR C interface

**A supplies:** `RealStep s e t`, the actual frozen source generator/state/effect relation, before/after relational observables, real subject-carry candidate, and explicit counterexamples.

**B must subsequently supply:** an **independently sourced** interpretation from those actual transitions to all six `ParticularFrame` predicates; rules for newborn/owed subjects; within-event continuity; consent authenticity; feasible actions.

**C then attempts:** `∀ s e t p, ActualStep s e t → Owed s p → FullOriginalX3 s e t p`. An entailment only from `Certified ...` whose fields already assert all six conclusions is not a discharge of physical necessity.
