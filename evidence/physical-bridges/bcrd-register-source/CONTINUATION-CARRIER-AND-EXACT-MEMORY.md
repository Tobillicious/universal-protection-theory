**Proof.** H_lambda(x,0)=(Bx,lambda Ax). Given any y, choose x=lambda-inverse A-inverse y. Then subtract (Bx,0), already in the UP subspace, from H_lambda(x,0), obtaining (0,y). ## SRN-6 — Exact source-derived non-Markovian UP memory

The Schrödinger equations are

    i xdot=Bx+lambda Ay,    i ydot=lambda Ax+Dy.

The second equation has the exact solution

    y(t)=exp(-iDt)y0 - i lambda integral_0^t exp(-iD(t-s)) A x(s) ds.

Substituting into the first yields

    xdot(t)=-i B x(t)
             -i lambda A exp(-iDt)y0
             -integral_0^t K(t-s)x(s) ds,

    K(u)=lambda² A exp(-iDu) A.             (SRN-6)

This memory kernel is obtained by **exactly eliminating part of the supplied closed Hamiltonian model**. It is not an inserted environmental bath or physically derived GKSL generator. K(0)=lambda²A², with Gram-physical eigenvalues lambda²/16 and 9lambda²/16. It is invertible for nonzero lambda.

If y0=0, the UP initial derivatives are xdot(0)=-iBx0 and xddot(0)=-(B²+lambda²A²)x0. Any *time-homogeneous first-order linear memoryless UP-amplitude equation* xdot=Lx matching the first derivative for every x0 must have L=-iB, giving second derivative -B²x0 and contradicting the actual source. This is a **restricted no-go**: it does not exclude other exact memory variables, time-dependent models, nonlinear histories, or use of the full source.

## SRN-7 — Current UP data do not predict every full-source history

Choose nonzero x0 and y0. The full normalized vectors proportional to (x0,+y0) and (x0,-y0) have identical UP components and identical total physical Gram norm (the register inner product is block diagonal). But
