# G3/G5/G6 source-locked causal-cut witness (non-canonical)

**Research draft, 28 October 2026 — conditional finite model only. Not part of the published Snuffy edition.**

This folder recovers the broad 18 October reach-or-hold architecture as a separate research obligation, and supplies a small, exhaustively checked **common toy witness** for founding, typed resources, independent authorization, and local attack interception. It is intentionally not an unconditional universal protection theorem, a physical BCRD derivation, or an empirically demonstrated installation.

## Replay

From the repository root:

```sh
python3 evidence/physical-bridges/g356-causal-cut/check_g356_witness.py
```

Uses standard-library Python. The checker exhaustively traverses 18,496 one-step input/attack combinations of the *model's* admitted three epochs and confirms 256 reachable final trace states. Negative controls include missing guards, common-mode failure, an unprotected new arrival, and an unguardable bypass.

## Unresolved obligations

1. Founding equilibrium is **selected**, not inevitable; decline/decline is another equilibrium.
2. Arrival C uses a **preprotected** port; truly arbitrary external reach remains unproved.
3. Authorization is stipulated independent and nonforgeable; causal participation does not imply consent.
4. Local guards are assumed installed, correct, fault-free and resource-feasible within the model's attack envelope.
5. The graph is a finite toy, not the complete causal graph of BCRD-compatible dynamics.
6. The broad historical P3 coverage premise already assumed bounded reach-or-hold. There is no new proof of physical universal coverage here.

**Review stance:** Keep this draft separate from manuscript canon. Any stronger physical claim requires a source-complete attack graph, explicit BCRD dynamics, time/deadline refinement, independently justified guard behavior, fault residuals, and a common feasible resource/founding witness.
