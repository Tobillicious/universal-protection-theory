2. **Authorization provenance**: for each discretionary effect, the trusted allow/deny input equals an independently validated genuine subject direction; it is not reconstructed from causal ancestry, coerced reaction, source parity, work result or operator claim.
3. **Faithful safe effects and continuing identity**: lawful source transitions preserve I; denied mediated effects are actually inert; permitted effects are physically faithful, preserve I and occur only with genuine authorization plus an independently valid safety/service certificate. I must have independently justified particular-process semantics, not be defined as “the controller says safe”.
4. **Nonblocking agency**, separately: every relevant protected state has at least two distinct **genuinely eligible** lawful physical successors, the defender can effect them, and neither is suppressed merely because doing so is simpler than protecting. This does NOT itself establish all feasible original X3 freedoms.

**Composition theorem:** If I(x0), premises 1–3 hold in the **same** actual R system, then every finite actual R-execution preserves I and each permitted mediated effect has genuine authorization and the separately certified safety/service property. If 4 also holds, the stated distinct lawful alternatives remain available along every such finite execution.

**Proof:** Induct on the actual R-steps. For each step, use independent coverage 1 to determine whether the physically real event is lawful or routed before its effect. In the lawful case 3 preserves I. In the routed case 2 ensures the guard's trusted authorization reflects genuine subject direction, while 3 ensures either a physically inert denial or a permitted effect that preserves I; no unauthorized discretionary effect is executed. Repeat for every step. Condition 4 applies at each reached protected state and preserves the declared alternatives; it is **not a consequence of safety alone**. □

This is a conditional logical composition rule. If R is *defined* to consist only of gate-approved actions, hypothesis 1 has been assumed into existence. **No general physical X3 claim is established from this theorem alone.**
