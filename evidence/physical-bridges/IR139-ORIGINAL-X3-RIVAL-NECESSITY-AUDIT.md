## Purpose

The original UPT objective has FOUR lexicographic stages: existing continuations, existing freedoms, new continuations, new freedoms, retaining genuinely same particulars, not replacing them with copies, records or index entries. ALL relevant particulars and relations (mind/nonmind; current/new; hosted/external) remain within the original domain. This PR neither revises that domain nor converts a finite guard construction into the definition of protection.

Existing IR-7 already proved a no-needless-loss result at the FIRST stage. IR-139 extends this into a **complete generic necessity theorem for EACH of the four original priority stages** and a source-execution counterexample certificate.

## New exact result (full original feasible family, not safe menu)

Let P be the set of all original particulars, O the feasible-outcome type, and F the COMPLETE original physically feasible family.

For a selected outcome s and executable challenger c, let K₁...K₄ denote the four original retention predicates, compared by the existing UPTExist LexBetter order.

**IR-139 necessity theorem:** if (i) c belongs to F and (ii) c strictly adds retained particulars at priority stage j, then a globally maximal selection s can survive the challenge ONLY if c loses some actual named particular at an EARLIER priority stage. Otherwise c strictly improves s and contradicts global maximality. No constraints are placed on lower-priority losses, because earlier improvements already dominate them under the author's existing order.

The argument even permits c to gain more retained particulars at earlier priority stages: the only escape is the loss of one or more earlier-stage particulars (which may make the alternatives incomparable rather than strictly ordered).

At j=1, no earlier priority exists: **any fully feasible strict improvement of existing continuation refutes global maximality immediately**, with no enumeration of all other alternatives required.

This is a necessary law of maximality, not a proof that an impossible/unknown rescue suddenly becomes physically feasible.

## Hostile no-go control

The theorem complete_maximality_does_not_imply_physical_survival gives a genuine complete feasible family (one outcome; every first-stage particular ends) where the feasible outcome is globally maximal. A feasible **ordering** cannot guarantee physical survival of an originally existing particular if physics offers no alternative. It is illegitimate to prove the law of no *avoidable* loss and conclude an unconditional universal physical protector exists.

This is not a retreat from X3; it is the exact interface that the physical proof must discharge, rather than concealing it behind vocabulary.

## Physical proof obligations still unmet

1. **Authentic feasible family.** The physical source relation includes every actual alternative device, interaction, attacker, unseen side channel, new life, resource deadline, and genuine action-reactive outcome. An internal safe menu is NOT the full F.
2. **Genuine original identity and freedom.** The four retention predicates faithfully measure actual individual continuation, actual independent self-direction and the original relational ontology, not copies, replay, or encoded descriptors.
3. **Actual counterfactual physical rescue.** A challenger must be executable with real time, capacity, pre-effect causal interception, authorization and shared finite resources. A purported repair action that is physically unavailable is not a rival.
4. **Universal reach and installation.** IR-139 turns a viable independently documented strict rescue into a logical contradiction for a purported maximal policy. It does NOT imply there exists a guardian reaching every external agent or preventing a physically inevitable death. Full P3/P4c, initial founding, late entrants and bypasses remain open.
5. **Common observation / policy.** The physically feasible policies must respect the actual sensors and causal information. IR-135 has a conflicting-hidden-world counterexample; per-world perfect policies are not one common policy.
6. **Joint fault/time.** All stages share one clock and correlated physical event space. Positive per-date failure risk need not give forever preservation.
