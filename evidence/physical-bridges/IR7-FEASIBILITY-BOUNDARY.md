# IR-7: Physical safety filters must not silently narrow the canonical order

The Snuffy order retains every original stage, including **all existing particulars**. A merely safe-controller-maximal outcome is NOT necessarily maximal in the original feasible family.

Formal result: If a nonempty safe finite family is included in the original feasible family, and **each excluded feasible option is strictly dominated in the existing UPT lexicographic order by some included safe option**, then an existing `UPTExist.lex_aligned_exists` choice in the safe family is maximal in the full feasible family too. This source-level join imports the actual unchanged `UPTExistence.lean` into the independent bridge package.

The cofinality condition is very strong. It must be justified from physical reachability, semantics, and the *original* feasibility definition; it does not follow from safety or viability alone. If cofinality fails, no full-global-maximality conclusion is available.

No preference weighting, changed stage priority, or redefinition of X3 occurs. The proof is conditional and is not a demonstration that every original freedom can be jointly realized.
