\begin{abstract}
We formalize the ontological ground of the Universal Protection Theorem
in Lean~4 dependent type theory. The central argument: any inhabited type
refutes the absolute ender, and this refutation requires no axioms beyond
the type system itself. We define the \texttt{AllIsActuality} structure ---
an inhabited, non-collapsing, decisive predicate over any type --- and prove
that its existence is constructive: \texttt{Bool} suffices as a witness.
The summit test shows that decisiveness forces a unique outcome: the predicate
either holds everywhere or nowhere, with no intermediate state. We prove that
existence is not a predicate but a structural ground from which protection
follows as a type-theoretic consequence. All theorems are verified in Lean~4
with zero custom axioms.
\end{abstract}

\section{Introduction}

The question ``why is there something rather than nothing?'' has traditionally
been treated as metaphysical. We show it admits a type-theoretic answer with
machine-verifiable consequences.

In dependent type theory, a type $P$ is \emph{inhabited} if there exists a
term $w : P$. The \texttt{AbsoluteEnder} structure asserts that a type is
empty --- that no such term exists. These two assertions are contradictory:
a witness of $P$ refutes the claim that $P$ is empty. This is not a contingent
fact about particular types; it is a structural property of the type system itself.

The contribution of this paper is threefold:
\begin{enumerate}
    \item We formalize the \texttt{AllIsActuality} structure, capturing the
    three properties of ontological ground: inhabitation, non-collapse, and
    decisiveness.
    \item We prove the structure is constructively inhabited (\texttt{Bool}
    witnesses it with zero axioms).
    \item We connect the ontological ground to the summit closure of
    the Universal Protection Theorem.
\end{enumerate}

\section{The AllIsActuality Structure}

\begin{definition}[AllIsActuality]
For a type $P$, the \texttt{AllIsActuality} structure consists of:
\begin{enumerate}
    \item A predicate $\text{actual} : P \to \text{Prop}$.
    \item A witness $w : P$ such that $\text{actual}(w)$ holds.
    \item Non-collapse: $\exists\, x : P,\; \neg\, \text{actual}(x)$.
    \item Decisiveness: $\forall\, x : P,\; \text{actual}(x) \lor \neg\, \text{actual}(x)$.
\end{enumerate}
\end{definition}

\begin{theorem}[Constructive Inhabitation]\label{thm:inhabit}
\texttt{AllIsActuality Bool} is nonempty:
\[
\text{Nonempty}(\texttt{AllIsActuality}\; \texttt{Bool})
\]
\textbf{Proof.} Take $\text{actual}(b) := (b = \texttt{true})$. Then:
\begin{itemize}
    \item Witness: $\texttt{true}$ with $\texttt{true} = \texttt{true}$.
    \item Non-collapse: $\texttt{false}$ with $\texttt{false} \neq \texttt{true}$.
    \item Decisiveness: by decidable equality on \texttt{Bool}.
\end{itemize}
Zero axioms. \qed
\end{theorem}

\section{The Decisive Summit Test}

\begin{definition}[DecisiveSummitTest]
For an \texttt{AllIsActuality} structure on $P$, the summit test determines
whether a given element is actual:
\[
\text{summit}(x) := \text{actual}(x) \lor \neg\, \text{actual}(x)
\]
By decisiveness, this always resolves. The summit test is total.
\end{definition}

\begin{theorem}[Summit Forces Binary Outcome]\label{thm:summit}
For every element $x : P$ in an \texttt{AllIsActuality} structure:
the summit test yields either $\text{actual}(x)$ or $\neg\, \text{actual}(x)$.
There is no third option, no undecided state, no partial collapse.
\end{theorem}

\section{From Inhabitation to Ender Refutation}

\begin{theorem}[Inhabitation Refutes Ender]\label{thm:refute}
For any type $P$ and witness $w : P$:
\[
\texttt{AbsoluteEnder}(P) \to \bot
\]
\textbf{Proof.} The \texttt{AbsoluteEnder} structure provides
$\text{empty} : P \to \text{False}$. Applying to $w$ yields
$\text{empty}(w) : \text{False}$. \qed

Zero axioms. This is the core of \texttt{e\_is\_not}.
\end{theorem}

\begin{corollary}[Universal Refutation]\label{cor:universal}
For all types $P$ and all witnesses $w : P$:
\[
\forall\, (P : \text{Type})\, (w : P),\; \texttt{AbsoluteEnder}(P) \to \bot
\]
The refutation is universal: it applies to every inhabited type, not just
particular ones.
\end{corollary}

\section{Existence Is Not a Predicate}

The traditional Kantian objection --- ``existence is not a real predicate'' ---
is precisely correct in our framework. Existence is not a predicate \emph{on}
types; it is the \emph{ground} from which predicates become meaningful.
A witness $w : P$ does not assert a property of $P$; it \emph{is} the
structural fact that makes $P$ available for predication.

The \texttt{AllIsActuality} structure shows this concretely: the predicate
$\text{actual}$ is defined \emph{on elements of an already-inhabited type}.
Inhabitation is prior to predication.
