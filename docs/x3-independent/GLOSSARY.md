## Original X3
Historical continuity: identity through history; a copy alone is insufficient.
Authorization: authentic permission or applicable justified rule.
Freedom: preservation of required future options.
Appropriate restraint: justified prevention of prohibited effects.
Maximality: nondominance among feasible admissible outcomes under a justified order.
Provenance: authentic correspondence of identity, effects and history.
These are glosses of the six relation parameters in OriginalX3Full.lean, not complete source semantics.

## Runtime and formal methods
| Term | Meaning |
|---|---|
| RUN / HOLD / RECOVERY | Proposed abstract operating modes; HOLD blocks new commits, recovery reconciles state. |
| Generation | Version or epoch used to distinguish stale authority. |
| Independent custody | Checkpoint authority outside the protected process's trust boundary. |
| Receipt | Evidence record binding an effect to relevant identity, history and authority. |
| Linearization point | Abstract instant at which a concurrent operation takes effect. |
| Invariant | Predicate preserved by permitted transitions. |
| Z | State-based formal specification notation. |
| ProB | Animator and model checker supporting Z. |
| CSP | Communicating Sequential Processes, a process algebra for concurrency. |
| Lean | Interactive theorem prover. |
| Refinement | Establishing that concrete behaviour conforms to an abstract specification under a defined relation. |
| Stuttering | Concrete transition with no relevant abstract state change. |
| Coverage | Evidence that all in-scope effects are represented and mediated. |
| Reflection | Justified implication from modeled/observed behaviour to the intended source predicate. |
| hCoverage / hReflection | Explicit premises of the full physical domain assembly, not automatically discharged by that theorem. |
| Negative control | Deliberately failing case used to test whether a check detects a violation. |
| Model checking | Exploring a specified model's behaviours; finite checks alone do not prove unrestricted physical claims. |
| Kernel replay | Rechecking formal proof terms with the theorem prover's trusted kernel. |
